# Terraform Provider for Apache Polaris

A [Terraform](https://www.terraform.io/) provider for [Apache Polaris](https://polaris.apache.org/),
the interoperable, open source catalog for [Apache Iceberg](https://iceberg.apache.org/).

> **Status: early development.** This repository is being bootstrapped and does
> not yet contain a usable provider. There are no releases and no published
> registry entry yet.

## Getting involved

Development happens in the open on the Apache Polaris mailing lists and in this
repository's issues and pull requests.

- Website: https://polaris.apache.org/
- Dev mailing list: dev@polaris.apache.org (subscribe by emailing dev-subscribe@polaris.apache.org)
